# 游戏设计 · 当前权威版

> 2026-11-06。此前《黑色电影桌面 RPG · 设计与实施文档》保留在 \`ORIGINAL-PLAN.md\` 作历史参考；与本文件冲突时，以本文件为准。

## 一句话

玩家不是破案机器，而是一个在黑色电影港口城市生活的侦探。时间、钱、工具与人手都有限；人物与城市不会等玩家。玩家每天做过的具体事情成为他们之后生活与命运的依据。

## 体验支柱

1. **分配就是玩法。** 拿有限的每日行动力决定去赚钱、查案、帮人还是陪人，不靠长选项列表代替行动。
2. **人物自己生活。** 人物有工作安排、他人的要求、个人目标和不可完全受玩家控制的结局。玩家不去见他，他也在变化。
3. **具体行为留下后果。** 谁在场、做了什么、用什么、结果如何，写入事实；未来事件与结局查事实、时钟、旗标，而不是泛化的善恶计量。
4. **生活规模逐渐展开。** 初期为一日的饭钱与案件奔波；中段结交人物、需要协调彼此；末段旧账与关系共同兑现。
5. **失败也推动剧情。** 失败留下风险、伤与欠账，通常不直接 Game Over。

## 明确删除的两套概念

- **关系账户**：不设计「陪伴存信任、借用扣信任」的可交易好感度。人物关系以经历、承诺、冲突、当前处境和个体判断表达。借用人手用该人物自身的**空闲时间**，而非购买信任。
- **明暗道路**：不统计明/暗牌比例、不以牌色染人、不凭道德积分自动升级警方或地下道路。法律身份、帮派关系、个人声誉可通过未来的具体事件与事实获得；一张枪牌并不自动代表坏人。

作为结果，**卡牌暂时只保留花色与点数**，具名物品与人物影响叙事及可进行的行动，不再包含道德颜色。未来允许作者为特定牌定义具体可见的代价，但不重新引入隐含道德指数。

## 一天的核心循环

清晨行动力恢复（主角默认6点）→在地图选节点和行动→拖入至多3张卡牌，选额外行动力0—2点→实时查看成功/有代价/失败概率→落子立即结算，时钟、资源和日记当场变化→收工触发人物/城市每天的自主行动。

熬夜：当天最多透支2点行动力，透支每点增加1压力，并减少次日可用行动力1点。

行动的概率由「牌点数 + 额外行动力 − 压力惩罚 − 行动难度」对应7档固定查表生成；允许无牌尝试但往往概率较低。人物卡牌占用其**实际空闲时间**，可以在空闲时间内多次帮助，不凭亲近度生成额外次数；其他牌用过当天休息，一次性牌用后消失。

风险钟与进度钟有明确的可见后果；风险满格应触发新的处境，而不是默认结案。现有探案流程是桌面操作和资源冲突的载体，不是唯一的胜利条件。

## 七天体验切片

- 旧仓库的「林深失踪案」作为可重复演示的工作线；事务所可做普通委托赚生活费。
- 码头工人阿砖：工头每天催促他签合同，玩家可为他争取另一条出路；周五可以陪他吃面。
- 即使玩家不理他，工头的催促也会推进。玩家帮他并不保证圆满，结局引用事实与处境。
- 核心评估：玩家是否真实觉得「去陪他吃面」需要放弃另一件有价值的事；是否因为这个人而改变一天的安排。

### 已实现与尚未实现

**当前可运行骨架**：地图与档案、拖牌、行动力/透支、统一牌判定、即时结算、风险与进度钟、日结算、简单事实与记忆、阿砖七天线、浏览器本地自动保存。现有文案和案件素材来自旧原型，仍属迁移内容。

**尚未实现**：丰富的角色自主反应表、真正的内容事件队列、契约小地图、人物特殊主张与拒绝、演出/爱情主线、完整故事文本拼接与最终卡片尾声。这些是扩展计划而非当前功能。

## 设计检验问题

玩家在看不到下一段新剧情时还会主动分配行动力吗？有无真正的时间机会成本？人物会不会让玩家感到独立存在，而不只是一个自动进度条？即使删掉一个完整模块，游戏是否仍然保留其核心体验？
