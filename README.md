# Black Table RPG · 雨夜侦探桌

一款黑色电影风格的桌面式都市生活 RPG。玩家用有限行动力和手里的牌，处理工作、事件、人物和麻烦；城市与人物在玩家不介入时仍会向前运行。故事记录的是玩家具体做过的事，而不是抽象的道德阵营数值。

## 运行

使用 Node.js 20+，在仓库根目录执行：

```bash
npm run dev
```

打开终端显示的本地地址（默认 http://localhost:4173）。项目使用浏览器原生 ES Modules，**无运行时依赖**。测试：`npm test`。

## 目录

- `index.html` — 入口及桌面 DOM 结构
- `src/styles.css` — 从初版「雨夜侦探桌」延续的视觉样式
- `src/data/` — 地图与作者内容；新角色和故事从这里添加
- `src/engine/` — 与 DOM 无关的游戏状态、判定、行动与日结算
- `src/main.js` — 地图、档案卡、拖拽、时钟、日记
- `tests/` — Node 内置测试
- `docs/` — 设计原则、实施路线与原始方案
- `legacy/` — 最初 HTML 原型（只读保留作对照）

## 设计边界

- 保留：行动力分配、卡牌与节点、进度与风险时钟、人物自主变化、行为事实、少量高压事件。
- 不做：将人物好感度当可存取账户；将行为归为明/暗并自动走警方/地下阵营；自由合成与复杂牌组构筑。
- 当前目标：先让一个短周期的人物事件在完整系统架构中可玩，再扩写人物与长篇故事。

现有原型的 UI 和旧数据保留为迁移参考；设计取舍详见 `docs/DESIGN.md`，阶段验收见 `docs/ROADMAP.md`。
